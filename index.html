    About this calculator

    This offline implementation reproduces the six variables and displayed point values described on the Appcardio PARIS Thrombosis Risk Score Calculator page: Diabetes Mellitus (+1), Current Smoking (+1), ACS as indication for PCI (+1), Prior PCI (+1), Stent Diameter < 3 mm (+1), and Multivessel PCI (+2). Maximum displayed score: 7.

    Risk bands shown by the source page: 0–2 Low Risk; 3–4 Intermediate Risk; greater than 5 High Risk. The source page does not specify a category for exactly 5 points, so this implementation flags that score as unspecified rather than inventing a category.

    Clinical caution

    This reproduces the parameters and point descriptions shown on the referenced website; it does not independently establish that these inputs and thresholds match the original validated PARIS model. Verify with a qualified clinician and the primary literature before any clinical use. This is an independent project, not affiliated with or endorsed by Appcardio.

    Reference
